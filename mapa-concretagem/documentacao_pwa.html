Mapa de Concretagem - Documentação Técnica

Visão Geral do PWA

O Mapa de Concretagem é um Progressive Web App (PWA) offline-first utilizado para gerenciar o planejamento, liberação de formas, produção (concretagem) e inspeção (montagem de postes). O sistema foi refatorado para deixar de utilizar o Google Sheets (via Google Apps Script) como banco de dados e passar a utilizar o Supabase (PostgreSQL).

Tecnologias Utilizadas

  • Frontend: HTML5, CSS3, JavaScript (Vanilla), Chart.js (Dashboards).
  • Backend / Banco de Dados: Supabase (PostgreSQL), Supabase JS Client.
  • Estratégia Offline: Armazenamento via localStorage (cache de dados e fila de sincronização) com Service Worker para PWA.

Fluxo de Arquitetura

PWA (Frontend / LocalStorage)
↔
Supabase Client SDK
↔
Supabase (PostgreSQL)

Estratégia de Inicialização do Cliente Supabase

O app.js foi atualizado para carregar o cliente do Supabase e remover as funções de fetch utilizadas com o Apps Script.

const SUPABASE_CONFIG = {
  URL: "https://[ID].supabase.co",
  KEY: "eyJ..."
};
const supabaseClient = window.supabase.createClient(SUPABASE_CONFIG.URL, SUPABASE_CONFIG.KEY);

O fluxo de offline (salvando payloads nas chaves do localStorage) permanece. O sincronizador em segundo plano agora consome os dados locais e insere as informações diretamente no banco PostgreSQL na nuvem sempre que a conexão (online) é restabelecida.
