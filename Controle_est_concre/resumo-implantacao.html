Arquitetura final

Frontend QR: o PWA em qr-concreto/index.html continua enviando o registro para o Apps Script.
Planilha: o Apps Script continua gravando normalmente na aba dados da planilha Google Sheets.
Banco VPS: o mesmo Apps Script foi ajustado para espelhar cada salvamento para a API da VPS em http://31.97.241.84:8086/api/v1/rompimentos.
API: serviço Node.js com Express e PostgreSQL executando sob PM2 e servido externamente por Nginx.

Fluxo de gravacao

1. Operador le o QR no PWA.
2. PWA envia os dados para o Apps Script do Google.
3. Apps Script salva na planilha mantido.
4. Apps Script envia o mesmo payload para a API da VPS novo.
5. API grava no PostgreSQL.
6. PWA exibe o status final com base no retorno vps_sync.

Pendencia operacional

A infraestrutura da VPS esta pronta. Para a escrita dupla entrar em producao, ainda e necessario publicar a versao atualizada do arquivo qr-concreto/AppsScript_qrConcreto.gs no Web App do Apps Script vinculado a planilha.
