# Referência visual — ConcreTrack Injeção

Arquivos aprovados como referência obrigatória para o frontend.

- Tablet operacional: 1280×800, paisagem, sem rolagem na tela principal.
- Desktop administrativo/gerencial: 1440×900 como base.
- `estilo.css` contém os tokens visuais e componentes de referência.

Mapeamento:
- `02-tablet-identificacao.html`: identificação e abertura.
- `01-tablet-apontamento.html`: apontamento operacional.
- `03-tablet-parada.html`: paradas e ocorrências.
- `04-desktop-painel.html`: painel gerencial.
- `05-desktop-perdas.html`: perdas e histórico.
