# Reconciliacao de importacao

Tabela principal: `import_reconciliation`.

A reconciliacao registra metricas do lote:

- linhas lidas;
- linhas validas;
- linhas rejeitadas;
- linhas importadas;
- duplicidades;
- arquivos reais disponiveis.

O objetivo e provar que a carga historica e reproduzivel e auditavel antes de tocar tabelas de dominio.
