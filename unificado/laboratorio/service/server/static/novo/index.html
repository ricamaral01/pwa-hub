Como a informação chega à sua tela

Seu hardware continua simples. O histórico fica no computador ou servidor que recebe os dados.

01 · MEDIR4 termopares tipo T

T1 núcleo, T2 centro, T3 próximo à forma e T4 ambiente.

→
02 · CONVERTER4 × MAX31856

Um conversor por sensor. SPI compartilhado com CS independentes.

→
03 · TRANSMITIRESP32 + Wi-Fi

Envia leituras ao IP configurado e recebe o intervalo de gravação.

→
04 · ACOMPANHARServidor + painel

Salva arquivos diários e serve a interface para PC, tablet e celular.

Três tempos diferentes. Os sensores são lidos a cada 5 segundos. O ESP32 envia o estado ao vivo a cada 10 segundos. Só uma amostra a cada intervalo escolhido entra no histórico: por exemplo, uma a cada 5 minutos. Cada registro reúne os quatro canais no mesmo instante de aquisição.
Sem internet, mas com rede local. A rede precisa alcançar o IP do servidor; a internet pública não é necessária. O relógio é sincronizado com esse servidor. Se o coletor ligar sem conexão, os horários anteriores à primeira sincronização são estimados pelo tempo desde o boot e identificados como estimados.
Quando o Wi-Fi cai. As amostras de histórico entram numa fila de 720 registros. Ao reconectar, saem em lotes com confirmação e identificador para evitar duplicação. A 1 minuto, a fila cobre aproximadamente 12 horas. Depois de cheia, descarta a amostra mais antiga e aumenta o contador de perdas. Sem energia, a fila é perdida.
Segurança. A API exige uma chave de coletor para enviar dados e outra, administrativa, para consultar e configurar. HTTP é destinado somente à rede local confiável ou à rede privada por VPN. Não exponha a porta diretamente à internet. O token administrativo fica apenas na sessão desta aba.

Limites de uso. O painel é um módulo de medição e histórico, não um critério automático de resistência ou desforma. Os picos são calculados com todas as amostras gravadas do período; o pico físico pode ocorrer entre amostras. Gráficos longos usam médias de janelas e informam essa redução; o CSV mantém os registros originais.
