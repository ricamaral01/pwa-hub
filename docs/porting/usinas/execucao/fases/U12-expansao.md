# U12 — Repetição para as demais tabelas

**Resultado:** **não iniciada como migração**. O inventário já identifica candidatas MISTAS e telas/funções de leitura. Nenhuma aprovação de uma tabela autoriza automaticamente outra. Pederneiras/Noroeste têm dados, posições e regras que devem conservar identidade própria; CEC, PCP, Dashboard e Etiquetas têm serviços e bancos correlatos.

**Sequência prevista:** repetir classificação e mapeamento, espelho, reconciliação, interface de leitura e, somente se autorizada, homologação de escrita por **tabela, ação e unidade**. Tabelas volumosas ou com efeitos em várias linhas exigem estratégia de sync e testes específicos.

## Pendências para aprovação

- Priorizar a próxima tabela/unidade para homologação de **leitura** e os casos de referência. Nenhuma ampliação de permissões da origem foi feita.
- Para qualquer expansão de edição, aprovar cada recorte após U07–U11 próprios e resolver o impedimento técnico registrado em U09. Até lá, usar o legado para editar e o Unificado apenas onde o espelho foi validado.
